## 1. Investigar els objectes

## 3. Ordenar i seleccionar

Construeix un pipeline que mostri els **cinc processos amb més CPU**.

La sortida ha de mostrar únicament:

```text
Name
Id
CPU
```

Compara després aquestes dues estratègies:

```text
ordenar → seleccionar 5
```

i:

```text
seleccionar 5 → ordenar
```

Respon:

1. Fan el mateix?

2. Per què?

3. Quants processos rep `Sort-Object` en cada cas?

> Per agafar els cinc amb més CPU primer els ordenem i després fem el First 5. Al final deixem només les tres propietats que demana:

```powershell
PS C:\Users\Administrador> Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name, Id, CPU
Name       Id    CPU
----       --    ---
opera    2980 608,84
opera   23292 399,73
opera   14228 223,23
```

> Ara canviem l’ordre per veure si dona el mateix:

```powershell
PS C:\Users\Administrador> Get-Process | Select-Object -First 5 | Sort-Object CPU -Descending | Select-Object Name, Id, CPU
Name                    Id  CPU
----                    --  ---
browser_assistant    16996 1,25
ApplicationFrameHost  4088 0,39
browser_assistant     2768 0,33
AggregatorHost        7380
ArcControlService     5148
```

> No fan el mateix. En el primer cas el sort rep tots els processos i després agafem els cinc primers de la llista ordenada. En el segon només rep els cinc que ja havíem seleccionat, així que pot deixar fora processos amb més CPU.
>
> En el primer pipeline arriben a `Sort-Object` tants objectes com processos retorni `Get-Process`; en el segon només n’arriben cinc. Per això el First 5 ha d’anar després d’ordenar si volem els cinc amb més CPU.
>
> El valor CPU d’aquesta taula és el temps de CPU acumulat en segons, no el percentatge d’ús d’aquell moment.

## 4. Primer filtre

Crea:

```powershell
$numeros = 5, 20, 3, 40, 12, 8, 30
```

Utilitzant `Where-Object`, mostra (adjunta comandes):

1. els números superiors a `10`;

2. els números inferiors a `20`;

3. els números iguals a `12`;

4. tots els números diferents de `20`.

Per cada cas identifica quin operador has utilitzat:

```text
-eq
-ne
-gt
-lt
-ge
-le
```

> Per provar els filtres creem l’array de números de l’enunciat:

```powershell
PS C:\Users\Administrador> $numeros = 5, 20, 3, 40, 12, 8, 30
PS C:\Users\Administrador> $numeros
5
20
3
40
12
8
30
```

> Amb -gt 10 deixem passar els que són més grans que 10:

```powershell
PS C:\Users\Administrador> $numeros | Where-Object { $_ -gt 10 }
20
40
12
30
```

> Ara fem servir -lt 20 per als que són més petits que 20:

```powershell
PS C:\Users\Administrador> $numeros | Where-Object { $_ -lt 20 }
5
3
12
8
```

> Per trobar el 12 fem servir -eq:

```powershell
PS C:\Users\Administrador> $numeros | Where-Object { $_ -eq 12 }
12
```

> I per treure el 20 deixant la resta utilitzem -ne:

```powershell
PS C:\Users\Administrador> $numeros | Where-Object { $_ -ne 20 }
5
3
40
12
8
30
```

> Aquí es veu que el filtre deixa els números en el mateix ordre en què estaven, només treu els que no compleixen la condició. Hem fet servir `-gt` per a més gran, `-lt` per a més petit, `-eq` per a igual i `-ne` per a diferent. Els altres dos són `-ge` (més gran o igual) i `-le` (més petit o igual).

## 5. Entendre `$_`

Utilitza:

```powershell
$numeros = 5, 20, 3
```

i analitza:

```powershell
$numeros |
    Where-Object { $_ -gt 10 }
```

Completa:

|Valor de `$_`|Resultat de `$_ -gt 10`|Passa el filtre?|
|---|---|---|
|5|`False`|No|
|20|`True`|Sí|
|3|`False`|No|

Explica amb les teves paraules:

**Què representa `$_`?**

> Ara deixem l’array amb aquests tres números i passem el filtre:

```powershell
PS C:\Users\Administrador> $numeros = 5, 20, 3
PS C:\Users\Administrador> $numeros | Where-Object { $_ -gt 10 }
20
```

> Per comprovar la taula podem provar la comparació de cada número per separat:

```powershell
PS C:\Users\Administrador> 5 -gt 10
False
PS C:\Users\Administrador> 20 -gt 10
True
PS C:\Users\Administrador> 3 -gt 10
False
```

> `$_` és l’element que està passant pel filtre en aquell moment. Primer val `5`, després `20` i després `3`. No representa tot l’array de cop. Com que només el 20 és més gran que 10, és l’únic que surt del filtre.

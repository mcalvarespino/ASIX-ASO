# Arrays

## 1. Crear un array

Crea un array amb aquests servidors:

```text
SRV01
SRV02
SRV03
SRV04
```

Guarda'l dins de:

```powershell
$servidors
```

Mostra tot el contingut de l'array.

> Per fer el primer hem ficat els 4 servidors a la variable i després l’hem mostrat per veure què hi havia dins:

```powershell
PS C:\Users\Administrador> $servidors = "SRV01", "SRV02", "SRV03", "SRV04"
PS C:\Users\Administrador> $servidors
SRV01
SRV02
SRV03
SRV04
```

> Aquí es veuen els 4 noms que hem guardat a `$servidors`, cada un és un element de l’array.

## 2. Accedir a posicions

Amb l'array anterior, mostra:

- el primer servidor;
- el segon servidor;
- el quart servidor.

Respon:

**Quina és la posició del primer element d'un array?**

> Ara agafem el primer, el segon i el quart servidor amb les posicions 0, 1 i 3:

```powershell
PS C:\Users\Administrador> $servidors[0]
SRV01
PS C:\Users\Administrador> $servidors[1]
SRV02
PS C:\Users\Administrador> $servidors[3]
SRV04
```

> El primer està a la posició `0`, no a la `1`. Per això per mirar el segon hem ficat `[1]` i per al quart `[3]`, com es veu a la sortida.

## 3. Comptar elements

Utilitza:

```powershell
.Count
```

per saber quants servidors hi ha dins de l'array.

Afegeix:

```text
SRV05
```

i torna a comprovar el nombre d'elements.

> Mirem quants servidors tenim abans d’afegir-ne cap:

```powershell
PS C:\Users\Administrador> $servidors.Count
4
```

> Ara fiquem `SRV05` amb `+=` i tornem a fer el count. També mostrem l’array per comprovar que s’ha afegit:

```powershell
PS C:\Users\Administrador> $servidors += "SRV05"
PS C:\Users\Administrador> $servidors.Count
5
PS C:\Users\Administrador> $servidors
SRV01
SRV02
SRV03
SRV04
SRV05
```

> Aquí es veu que abans teníem 4 servidors i ara en tenim 5. El que hem ficat surt al final, no ha substituït cap dels que ja teníem.

## 4. Modificar un element

Partint de:

```powershell
$servidors = "SRV01", "SRV02", "SRV03"
```

modifica el segon element perquè passi a ser:

```text
SRV-WEB01
```

Mostra després tot l'array.

> En aquest punt tornem a crear l’array amb els 3 servidors de l’enunciat i canviem el segon:

```powershell
PS C:\Users\Administrador> $servidors = "SRV01", "SRV02", "SRV03"
PS C:\Users\Administrador> $servidors[1] = "SRV-WEB01"
PS C:\Users\Administrador> $servidors
SRV01
SRV-WEB01
SRV03
```

> Hem ficat el nom nou a la posició `1` perquè és el segon element. Després hem mostrat l’array i es veu que ara surt `SRV-WEB01` al seu lloc, els altres dos no han canviat.

## 5. Array de ports

Crea un array numèric amb els ports següents: 22, 80, 443 i 3389.

Respon (i digues quina comanda has executat per obtenir la resposta):

- Quants ports hi ha?
- Quin és el primer?
- Quin és l'últim?
- Quin tipus té el primer element?

> Fem el mateix però ara amb els ports, els fiquem sense cometes perquè siguin números:

```powershell
PS C:\Users\Administrador> $ports = 22, 80, 443, 3389
PS C:\Users\Administrador> $ports
22
80
443
3389
```

> Amb el count comprovem quants ports hi ha:

```powershell
PS C:\Users\Administrador> $ports.Count
4
```

> El primer el mirem amb `[0]`, igual que hem fet abans amb els servidors:

```powershell
PS C:\Users\Administrador> $ports[0]
22
```

> Per mirar l’últim podem fer servir `[-1]`, així no cal comptar les posicions:

```powershell
PS C:\Users\Administrador> $ports[-1]
3389
```

> Ara comprovem el tipus del primer port amb el get type i mostrem el nom del tipus:

```powershell
PS C:\Users\Administrador> $ports[0].GetType().Name
Int32
```

> Ens dona 4 ports, el primer és `22` i l’últim `3389`. El primer és de tipus `Int32`, és a dir un enter, perquè hem ficat el número directament i no com a text entre cometes.

## 6. Array i variables

Crea:

```powershell
$servidor1 = "SRV01"
$servidor2 = "SRV02"
$servidor3 = "SRV03"
```

Després crea un array a partir d'aquestes variables:

Mostra'n el contingut.

> Per fer-ho primer declarem les 3 variables i després les fiquem juntes a l’array, així:

```powershell
PS C:\Users\Administrador> $servidor1 = "SRV01"
PS C:\Users\Administrador> $servidor2 = "SRV02"
PS C:\Users\Administrador> $servidor3 = "SRV03"
PS C:\Users\Administrador> $servidors = $servidor1, $servidor2, $servidor3
PS C:\Users\Administrador> $servidors
SRV01
SRV02
SRV03
```

> Aquí es veu que l’array guarda els valors de les variables. No hem tornat a escriure els noms, hem fet servir les variables que ja teníem declarades.

## 7. Resultats d'un cmdlet

Utilitza un array per determinar el nombre de processos que s'estan executant en el sistema.

> Ara guardem el que ens dona el get process en un array i després fem el count per saber quants processos hi ha:

```powershell
PS C:\Users\Administrador> $processos = @(Get-Process)
PS C:\Users\Administrador> $processos.Count
302
```

> En aquesta prova ens ha donat `302`. Amb `@(...)` ens assegurem de guardar el resultat com un array i després amb `.Count` comptem els elements, que en aquest cas són processos. Si ho tornem a fer pot donar un altre número perquè es poden obrir o tancar processos.

## 8. General

Crea un array:

```powershell
$servidors = "SRV-DC01", "SRV-DNS01", "SRV-WEB01", "SRV-FILES01"
```

Sense tornar a escriure els noms dels servidors manualment, mostra una sortida semblant a:

```text
Primer servidor: SRV-DC01
Últim servidor: SRV-FILES01
Nombre de servidors: 4
```

> Per acabar creem l’array que demana i fem els missatges agafant els valors de la variable, sense tornar a posar els noms a mà:

```powershell
PS C:\Users\Administrador> $servidors = "SRV-DC01", "SRV-DNS01", "SRV-WEB01", "SRV-FILES01"
PS C:\Users\Administrador> Write-Output "Primer servidor: $($servidors[0])"
Primer servidor: SRV-DC01
PS C:\Users\Administrador> Write-Output "Últim servidor: $($servidors[-1])"
Últim servidor: SRV-FILES01
PS C:\Users\Administrador> Write-Output "Nombre de servidors: $($servidors.Count)"
Nombre de servidors: 4
```

> Aquí hem fet servir `[0]` per al primer, `[-1]` per a l’últim i el count per saber quants n’hi ha. Dins del text hem ficat les expressions amb `$()` perquè amb les cometes dobles es mostrin els valors, com es veu a la sortida.

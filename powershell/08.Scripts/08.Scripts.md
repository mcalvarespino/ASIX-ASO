## 1. Informació bàsica del sistema

Crea un script anomenat:

```text
infoSistema.ps1
```

El script ha de mostrar:

- nom de l'equip;

- usuari actual;

- versió de PowerShell;

- data i hora actuals;

- directori actual.

La sortida ha de ser clara i llegible.

Per exemple:

```text
===== INFORMACIÓ DEL SISTEMA =====

Equip: ...
Usuari: ...
PowerShell: ...
Data: ...
Directori actual: ...
```

1. Adjunta el script final.
2. Explica el procés que has seguit o operacions que has executat abans d'obtenir el script final.

> Abans de fer el script hem anat mirant d’on podíem treure cada dada. Per al nom i l’usuari fem servir les variables de l’entorn, i després comprovem la versió, la data i el directori:

```powershell

WIN-FTMF63VOMCU
PS C:\Users\Administrador> $env:USERNAME
administrador
PS C:\Users\Administrador> $PSVersionTable.PSVersion.ToString()
7.6.7
PS C:\Users\Administrador> Get-Date -Format "dd/MM/yyyy HH:mm:ss"
22/10/2026 17:07:41
PS C:\Users\Administrador> (Get-Location).Path
C:\Users\Administrador
```

> Ara executem el script complet que hem guardat a `scripts tasca`:

```powershell
PS C:\Users\Administrador> & ".\scripts tasca\infoSistema.ps1"

```

> Aquí es veuen les dades del servidor, no les de l’equip des d’on fem la connexió. El nom de l’equip i l’usuari els agafem de les variables de l’entorn, i la versió, la data i el directori es consulten quan executem el script.

### Script final

```powershell
# Informacio basica de l'equip on executem el script.
$equip = $env:COMPUTERNAME
$usuari = $env:USERNAME
$versioPowerShell = $PSVersionTable.PSVersion
$data = Get-Date -Format "dd/MM/yyyy HH:mm:ss"
$directori = (Get-Location).Path

Write-Output "===== INFORMACIÓ DEL SISTEMA ====="
Write-Output ""
Write-Output "Equip: $equip"
Write-Output "Usuari: $usuari"
Write-Output "PowerShell: $versioPowerShell"
Write-Output "Data: $data"
Write-Output "Directori actual: $directori"
```

## 2. Estat dels serveis

Crea:

```text
estatServeis.ps1
```

El script ha de:

1. obtenir tots els serveis del sistema;

2. comptar quants estan en execució;

3. comptar quants no estan en execució;

4. mostrar el total de serveis;

5. mostrar els resultats al final.

Exemple:

```text
===== ESTAT DELS SERVEIS =====

Total: 230
Running: 95
Not running: 135
```

> Primer guardem els serveis i provem els dos filtres per separat:

```powershell
PS C:\Users\Administrador> $serveis = @(Get-Service)
PS C:\Users\Administrador> $enExecucio = @($serveis | Where-Object { $_.Status -eq "Running" })
PS C:\Users\Administrador> $noExecutats = @($serveis | Where-Object { $_.Status -ne "Running" })
PS C:\Users\Administrador> $serveis.Count
117
PS C:\Users\Administrador> $enExecucio.Count
49
PS C:\Users\Administrador> $noExecutats.Count
68
```

> Ara executem el script complet que hem guardat a `scripts tasca`:

```powershell
PS C:\Users\Administrador> & ".\scripts tasca\estatServeis.ps1"
===== ESTAT DELS SERVEIS =====

Total: 117
Running: 49
Not running: 68
```

> Els que estan Running i els que no ho estan sumen el total. Hem guardat els serveis una sola vegada per fer els tres recomptes sobre la mateixa llista. Amb `-ne "Running"` entren tots els altres estats, no només Stopped.

### Script final

```powershell
# Guardem els serveis per fer tots els recomptes sobre la mateixa llista.
$serveis = @(Get-Service)
$enExecucio = @($serveis | Where-Object { $_.Status -eq "Running" })
$noExecutats = @($serveis | Where-Object { $_.Status -ne "Running" })

Write-Output "===== ESTAT DELS SERVEIS ====="
Write-Output ""
Write-Output "Total: $($serveis.Count)"
Write-Output "Running: $($enExecucio.Count)"
Write-Output "Not running: $($noExecutats.Count)"
```

## 3. Processos amb més consum de CPU

Crea:

```text
topProcessos.ps1
```

El script ha de mostrar els **10 processos amb més consum de CPU**.

La sortida ha de mostrar únicament:

```text

Id
CPU
```

Després mostra també:

```text

```

> Ara executem el script complet que hem guardat a `scripts tasca`:

```powershell

MsMpEng    1868 328,48
System        4 171,45

svchost    1856  12,67

lsass       696  10,14

```

> Primer ordenem tots els processos per CPU i després agafem els deu primers. Al final mostrem el total de processos guardats, no només els deu de la taula. Si tornem a executar la comanda algun valor pot canviar. La CPU d’aquesta taula és el temps acumulat en segons.

### Script final

```powershell
# Ordenem abans d'agafar els deu primers processos.
$processos = @(Get-Process)
$topProcessos = $processos |
    Sort-Object CPU -Descending |
    Select-Object -First 10 Name, Id, CPU

$topProcessos | Format-Table -AutoSize
Write-Output "Nombre total de processos: $($processos.Count)"
```

## 4. Anàlisi de fitxers d'una carpeta

Crea:

```text
analitzaCarpeta.ps1
```

El script ha de treballar amb la carpeta des d'on s'executa.

Ha de mostrar:

- nombre total d'elements;

- els cinc fitxers més grans;

- nom i mida d'aquests fitxers.

Investiga les propietats retornades per:

```powershell
Get-ChildItem
```

i utilitza-les per construir el pipeline.

> Tingues en compte que pots trobar tant fitxers com carpetes.

> Per fer les proves entrem a `PracticaPipeline`, la carpeta que ja teníem al servidor:

```powershell
PS C:\Users\Administrador> Set-Location -LiteralPath "C:\Users\Administrador\PracticaPipeline"
```

> Primer mirem què hi ha a la carpeta del servidor i les propietats que ens dona Get-ChildItem:

```powershell
PS C:\Users\Administrador\PracticaPipeline> Get-ChildItem | Select-Object Name, Length, PSIsContainer
Name        Length PSIsContainer
----        ------ -------------
fitxer1.txt     12         False
fitxer2.txt     52         False
fitxer3.txt    102         False
fitxer4.txt    202         False
fitxer5.txt    502         False
fitxer6.txt   1002         False
```

> Ara traiem les carpetes i ordenem només els fitxers per Length:

```powershell
PS C:\Users\Administrador\PracticaPipeline> Get-ChildItem | Where-Object { $_.PSIsContainer -eq $false } | Sort-Object Length -Descending | Select-Object -First 5 Name, Length
Name        Length
----        ------
fitxer6.txt   1002
fitxer5.txt    502
fitxer4.txt    202
fitxer3.txt    102
fitxer2.txt     52
```

> Ara executem el script complet que hem guardat a `scripts tasca`:

```powershell
PS C:\Users\Administrador\PracticaPipeline> & "C:\Users\Administrador\scripts tasca\analitzaCarpeta.ps1"
===== ANÀLISI DE LA CARPETA =====
Nombre total d'elements: 6

Cinc fitxers més grans (mida en bytes):

Name        Length
----        ------
fitxer6.txt   1002
fitxer5.txt    502
fitxer4.txt    202
fitxer3.txt    102
fitxer2.txt     52
```

> També ho provem en una carpeta buida del servidor:

```powershell
PS C:\Users\Administrador\practica8-proves-20261022-ssh\prova-buida> & "C:\Users\Administrador\scripts tasca\analitzaCarpeta.ps1"
===== ANÀLISI DE LA CARPETA =====
Nombre total d'elements: 0

Cinc fitxers més grans (mida en bytes):
```

> En aquesta prova hi ha 6 elements: 6 fitxers i 0 carpetes. El total es calcula abans de filtrar. Després fem servir `PSIsContainer` per deixar només els fitxers i `Length` per ordenar-los per mida, en bytes.
>
> El script treballa amb el directori actual, no amb el lloc on està guardat el `.ps1`. També l’hem provat en una carpeta buida i en una que només té carpetes: mostra el total i no dona error encara que no hi hagi fitxers per ordenar.

### Script final

```powershell
# Get-ChildItem treballa amb el directori actual.
$elements = @(Get-ChildItem)
$fitxers = @($elements | Where-Object { $_.PSIsContainer -eq $false })
$fitxersGrans = $fitxers |
    Sort-Object Length -Descending |
    Select-Object -First 5 Name, Length

Write-Output "===== ANÀLISI DE LA CARPETA ====="
Write-Output "Nombre total d'elements: $($elements.Count)"
Write-Output ""
Write-Output "Cinc fitxers més grans (mida en bytes):"
$fitxersGrans | Format-Table -AutoSize
```

## 6. Processos pare

- El nom i id del procés (entre = a l'exemple).

> A cada bloc es veu el nom i l’Id del procés, el nombre de threads i després l’Id i el temps de cadascun. El script recorre tots els processos del servidor.
>
> Hi ha dades que poden sortir en blanc o amb `00:00:00`, com diu l’enunciat. Hem deixat el try i catch a les consultes dels threads perquè si un procés es tanca o una dada no es pot llegir no s’aturi tot el script.

### Script final

```powershell
# Alguns processos es poden tancar o no deixar consultar els seus threads.
$ErrorActionPreference = "Stop"
$processos = Get-Process

foreach ($proces in $processos) {
    Write-Output "============================== $($proces.ProcessName) ($($proces.Id)) =============================="
    Write-Output ""

    try {
        $threads = $proces.Threads
    } catch {
        $threads = $null
    }

    if ($null -eq $threads) {
        Write-Output "Total threads: no disponible"
        Write-Output ""
        continue
    }

    Write-Output "Total threads: $($threads.Count)"
    Write-Output ""

    foreach ($thread in $threads) {
        try {
            $tempsCPU = $thread.TotalProcessorTime
        } catch {
            $tempsCPU = ""
        }

        Write-Output "ID: $($thread.Id) CPU TIME: $tempsCPU"
    }

    Write-Output ""
}
```

# Arrays

## 1. Crear un array

Crea un array amb aquests servidors:
```text
SRV01
SRV02
SRV03
SRV04
```
Guarda'l dins de:
```powershell
$servidors
```
Mostra tot el contingut de l'array.

> Primer creem l’array amb els quatre servidors i en mostrem el contingut:

```powershell
PS C:\Users\Administrador> $servidors = "SRV01", "SRV02", "SRV03", "SRV04"
PS C:\Users\Administrador> $servidors
SRV01
SRV02
SRV03
SRV04
```

> Aquí es veuen els quatre noms guardats a la variable `$servidors`. Cada nom és un element de l’array.

## 2. Accedir a posicions
Amb l'array anterior, mostra:

- el primer servidor;
- el segon servidor;
- el quart servidor.

Respon:

**Quina és la posició del primer element d'un array?**

> Ara mostrem el primer, el segon i el quart servidor amb les seves posicions:

```powershell
PS C:\Users\Administrador> $servidors[0]
SRV01
PS C:\Users\Administrador> $servidors[1]
SRV02
PS C:\Users\Administrador> $servidors[3]
SRV04
```

> La posició del primer element és `0`. Per això el segon és a la posició `1` i el quart és a la `3`.

## 3. Comptar elements
Utilitza:
```powershell
.Count
```
per saber quants servidors hi ha dins de l'array.

Afegeix:
```text
SRV05
```
i torna a comprovar el nombre d'elements.

> Primer comprovem quants servidors hi ha a l’array:

```powershell
PS C:\Users\Administrador> $servidors.Count
4
```

> Ara afegim `SRV05` amb `+=` i tornem a comprovar el nombre d’elements i el contingut:

```powershell
PS C:\Users\Administrador> $servidors += "SRV05"
PS C:\Users\Administrador> $servidors.Count
5
PS C:\Users\Administrador> $servidors
SRV01
SRV02
SRV03
SRV04
SRV05
```

> Abans hi havia quatre elements i, després d’afegir `SRV05`, n’hi ha cinc. El servidor nou apareix al final de l’array.

## 4. Modificar un element

Partint de:
```powershell
$servidors = "SRV01", "SRV02", "SRV03"
```
modifica el segon element perquè passi a ser:
```text
SRV-WEB01
```
Mostra després tot l'array.

> Per fer aquest apartat, tornem a crear l’array de tres servidors que indica l’enunciat. Després canviem el segon element i mostrem el resultat:

```powershell
PS C:\Users\Administrador> $servidors = "SRV01", "SRV02", "SRV03"
PS C:\Users\Administrador> $servidors[1] = "SRV-WEB01"
PS C:\Users\Administrador> $servidors
SRV01
SRV-WEB01
SRV03
```

> Hem modificat la posició `1`, que correspon al segon element. Ara conté `SRV-WEB01` i els altres dos servidors es mantenen igual.

## 5. Array de ports

Crea un array numèric amb els següents ports: 22, 80, 443 i 3389

Respon (i digues quina comanda has executat per obtenir la resposta):

- Quants ports hi ha?
- Quin és el primer?
- Quin és l'últim?
- Quin tipus té el primer element?

> Creem l’array de ports i en mostrem el contingut:

```powershell
PS C:\Users\Administrador> $ports = 22, 80, 443, 3389
PS C:\Users\Administrador> $ports
22
80
443
3389
```

> Comprovem quants ports hi ha amb `.Count`:

```powershell
PS C:\Users\Administrador> $ports.Count
4
```

> Consultem el primer port amb la posició `0`:

```powershell
PS C:\Users\Administrador> $ports[0]
22
```

> Consultem l’últim port amb la posició `-1`:

```powershell
PS C:\Users\Administrador> $ports[-1]
3389
```

> Finalment comprovem el tipus del primer element amb `GetType()` i en mostrem el nom:

```powershell
PS C:\Users\Administrador> $ports[0].GetType().Name
Int32
```

> Hi ha quatre ports. El primer és `22`, l’últim és `3389` i el primer element és de tipus `Int32`, perquè l’hem escrit com un nombre enter, sense cometes.

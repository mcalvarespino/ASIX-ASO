# ASIX-ASO

## Presentació

Soc en **Marcos Calvar Espino**, estudiant d'Administració de Sistemes Informàtics en Xarxa (ASIX) i propietari d'aquest repositori. Aquí recullo les activitats del mòdul d'Administració de Sistemes Operatius (ASO).

## Objectiu i motivació

El repositori em serveix per documentar el que aprenc, practicar l'administració de sistemes i conservar l'evolució de les activitats amb Git. També hi incorporo les correccions del professor per revisar els errors i millorar les propostes.

# Estructures de control

## 1. Condicional

Crea:

```powershell
$port = 443
```

Mostra:

```text
Port HTTPS
```

si el port és `443`.

Canvia després el valor de `$port` i comprova què passa.

> Per fer el primer fiquem el port a 443 i comprovem si és el que demana:

```powershell
PS C:\Users\Administrador> $port = 443
PS C:\Users\Administrador> if ($port -eq 443) {
>>     Write-Output "Port HTTPS"
>> }
Port HTTPS
```

> Ara el canviem a 80 i tornem a passar pel mateix if per mirar què fa:

```powershell
PS C:\Users\Administrador> $port = 80
PS C:\Users\Administrador> if ($port -eq 443) {
>>     Write-Output "Port HTTPS"
>> }
```

> Amb el `443` ens ha mostrat `Port HTTPS`. Després hem ficat `80` i no ha sortit cap missatge perquè la condició ja no es compleix. Aquí no hem posat cap `else`, així que quan no és el 443 simplement continua sense entrar al bloc.

## 2. if o switch

Crea:

```powershell
$estat = 2
```

Fes que el programa mostri:

```text
1 → Iniciant
2 → Executant
3 → Finalitzat
4 → En espera
qualsevol altre valor → Estat desconegut
```

Resol el problema utilitzant `if` i `switch`. Compara les dues solucions.

> Comencem amb el valor 2. Amb if i elseif anem mirant quin estat coincideix, i si no en coincideix cap fem servir l’else:

```powershell
PS C:\Users\Administrador> $estat = 2
PS C:\Users\Administrador> if ($estat -eq 1) {
>>     Write-Output "Iniciant"
>> } elseif ($estat -eq 2) {
>>     Write-Output "Executant"
>> } elseif ($estat -eq 3) {
>>     Write-Output "Finalitzat"
>> } elseif ($estat -eq 4) {
>>     Write-Output "En espera"
>> } else {
>>     Write-Output "Estat desconegut"
>> }
Executant
```

> Fem el mateix amb switch, però ara tenim cada valor al costat del que ha de mostrar:

```powershell
PS C:\Users\Administrador> switch ($estat) {
>>     1 { Write-Output "Iniciant"; break }
>>     2 { Write-Output "Executant"; break }
>>     3 { Write-Output "Finalitzat"; break }
>>     4 { Write-Output "En espera"; break }
>>     default { Write-Output "Estat desconegut" }
>> }
Executant
```

> Per comprovar els altres casos provem els quatre estats i també el 9. Guardem les dues respostes i les mostrem juntes per comparar-les:

```powershell
PS C:\Users\Administrador> foreach ($estat in 1, 2, 3, 4, 9) {
>>     $resultatIf = if ($estat -eq 1) {
>>         "Iniciant"
>>     } elseif ($estat -eq 2) {
>>         "Executant"
>>     } elseif ($estat -eq 3) {
>>         "Finalitzat"
>>     } elseif ($estat -eq 4) {
>>         "En espera"
>>     } else {
>>         "Estat desconegut"
>>     }
>>     $resultatSwitch = switch ($estat) {
>>         1 { "Iniciant"; break }
>>         2 { "Executant"; break }
>>         3 { "Finalitzat"; break }
>>         4 { "En espera"; break }
>>         default { "Estat desconegut" }
>>     }
>>     Write-Output "Estat $estat -> if: $resultatIf | switch: $resultatSwitch"
>> }
Estat 1 -> if: Iniciant | switch: Iniciant
Estat 2 -> if: Executant | switch: Executant
Estat 3 -> if: Finalitzat | switch: Finalitzat
Estat 4 -> if: En espera | switch: En espera
Estat 9 -> if: Estat desconegut | switch: Estat desconegut
```

> Amb el `2` les dues formes ens han donat `Executant`. A les proves també es veu que l’1 dona `Iniciant`, el 3 `Finalitzat`, el 4 `En espera` i el 9 `Estat desconegut`, tant amb if com amb switch.
>
> El resultat és el mateix. En aquest cas el switch queda més curt perquè només comparem una variable amb diferents valors. Amb if i elseif hem anat escrivint les comparacions una per una, però també ens serviria si les condicions fossin diferents entre elles. El `default` del switch fa aquí el mateix paper que l’`else`: agafa els valors que no hem previst.

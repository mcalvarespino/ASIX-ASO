# `Select-Object` i `Where-Object`

> **Nota:** Els exercicis t'han de servir per familiaritzar-te amb PowerShell. No et limitis a executar les ordres: fes proves, modifica valors i propietats i observa què passa. Documenta les proves que consideris rellevants.
## 1. Investigar els objectes

Executa:

```powershell
Get-Process
```

Observa la informació que mostra PowerShell.

Ara investiga un procés amb:

```powershell
Get-Process |
    Select-Object -First 1 |
    Select-Object *
```

i:

```powershell

    Get-Member
```

> El `Get-Process` del principi no ens mostra totes les propietats, només les que té preparades per a la taula. Amb `Select-Object *` veiem les propietats i els valors d’aquell procés; amb `Get-Member` veiem els membres que té l’objecte, també els mètodes, però no és la mateixa sortida.
>
> Tres propietats que hem localitzat són `WorkingSet64`, `VirtualMemorySize64` i `Responding`. La primera indica la memòria física que utilitza el procés en bytes, la segona la memòria virtual i l’última si respon. Al final hem escollit `Name`, `Id` i `WorkingSet64` perquè així podem identificar el procés i mirar la memòria que està utilitzant.
>
> A les sortides molt llargues he deixat només un fragment i ho he marcat amb `...`; les comandes sí que s’han executat senceres.

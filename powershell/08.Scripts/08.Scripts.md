# Scripts PowerShell

L'objectiu d'aquesta pràctica és integrar els conceptes treballats durant la introducció a PowerShell:

- variables;
    
- tipus de dades;
    
- arrays;
    
- pipeline;
    
- `Select-Object`;
    
- `Where-Object`;
    
- propietats dels objectes;
    
- `if`, `elseif`, `else` i `switch`;
    
- `foreach` i `ForEach-Object`;
    
- scripts `.ps1`.
    

> **Important:** abans d'incorporar una ordre al script, és recomanable provar-la directament a la consola de PowerShell.
## 1. Informació bàsica del sistema

Crea un script anomenat:

```text
infoSistema.ps1
```

El script ha de mostrar:

- nom de l'equip;

- usuari actual;

- versió de PowerShell;

- data i hora actuals;

- directori actual.


La sortida ha de ser clara i llegible.

Per exemple:

```text
===== INFORMACIÓ DEL SISTEMA =====

Equip: ...
Usuari: ...
PowerShell: ...
Data: ...
Directori actual: ...
```

1. Adjunta el script final.
2. Explica el procés que has seguit o operacions que has executat abans d'obtenir el script final.

> Abans de fer el script hem anat mirant d’on podíem treure cada dada. Per al nom i l’usuari fem servir les variables de l’entorn, i després comprovem la versió, la data i el directori:

```powershell
PS C:\Users\Administrador> $env:COMPUTERNAME
DESKTOP-1NO6IQD
PS C:\Users\Administrador> $env:USERNAME
MSI
PS C:\Users\Administrador> $PSVersionTable.PSVersion.ToString()
7.6.5
PS C:\Users\Administrador> Get-Date -Format "dd/MM/yyyy HH:mm:ss"
22/10/2026 16:16:48
PS C:\Users\Administrador> (Get-Location).Path
C:\Users\MSI\Desktop\git\ASIX-ASO\powershell\08.Scripts
```

> Després hem guardat aquestes dades en variables i hem preparat els missatges perquè no surtin tots els valors sense saber què és cada un. Executem el script complet:

```powershell
PS C:\Users\Administrador> & ".\scripts tasca\infoSistema.ps1"
===== INFORMACIÓ DEL SISTEMA =====

Equip: DESKTOP-1NO6IQD
Usuari: MSI
PowerShell: 7.6.5
Data: 22/10/2026 16:16:48
Directori actual: C:\Users\MSI\Desktop\git\ASIX-ASO\powershell\08.Scripts
```

> Aquí es veuen les cinc dades que demana. La data i el directori es consulten quan executem el script, no els hem escrit a mà. Per mostrar la versió hem fet servir `$PSVersionTable.PSVersion` i ho hem provat amb PowerShell 7.

### Script final

```powershell
# Informacio basica de l'equip on executem el script.
$equip = $env:COMPUTERNAME
$usuari = $env:USERNAME
$versioPowerShell = $PSVersionTable.PSVersion
$data = Get-Date -Format "dd/MM/yyyy HH:mm:ss"
$directori = (Get-Location).Path

Write-Output "===== INFORMACIÓ DEL SISTEMA ====="
Write-Output ""
Write-Output "Equip: $equip"
Write-Output "Usuari: $usuari"
Write-Output "PowerShell: $versioPowerShell"
Write-Output "Data: $data"
Write-Output "Directori actual: $directori"
```

## 2. Estat dels serveis

Crea:

```text
estatServeis.ps1
```

El script ha de:

1. obtenir tots els serveis del sistema;

2. comptar quants estan en execució;

3. comptar quants no estan en execució;

4. mostrar el total de serveis;

5. mostrar els resultats al final.


Exemple:

```text
===== ESTAT DELS SERVEIS =====

Total: 230
Running: 95
Not running: 135
```

> Primer guardem els serveis i provem els dos filtres per separat:

```powershell
PS C:\Users\Administrador> $serveis = @(Get-Service)
PS C:\Users\Administrador> $enExecucio = @($serveis | Where-Object { $_.Status -eq "Running" })
PS C:\Users\Administrador> $noExecutats = @($serveis | Where-Object { $_.Status -ne "Running" })
PS C:\Users\Administrador> $serveis.Count
297
PS C:\Users\Administrador> $enExecucio.Count
132
PS C:\Users\Administrador> $noExecutats.Count
165
```

> Un cop vistos els recomptes els fiquem al script amb el títol i les etiquetes de cada número:

```powershell
PS C:\Users\Administrador> & ".\scripts tasca\estatServeis.ps1"
===== ESTAT DELS SERVEIS =====

Total: 297
Running: 132
Not running: 165
```

> Els que estan Running i els que no ho estan sumen el total. Hem guardat els serveis una sola vegada perquè els tres recomptes surtin de la mateixa llista. Amb `-ne "Running"` entren tots els altres estats, no només Stopped.

### Script final

```powershell
# Guardem els serveis per fer tots els recomptes sobre la mateixa llista.
$serveis = @(Get-Service)
$enExecucio = @($serveis | Where-Object { $_.Status -eq "Running" })
$noExecutats = @($serveis | Where-Object { $_.Status -ne "Running" })

Write-Output "===== ESTAT DELS SERVEIS ====="
Write-Output ""
Write-Output "Total: $($serveis.Count)"
Write-Output "Running: $($enExecucio.Count)"
Write-Output "Not running: $($noExecutats.Count)"
```

## 3. Processos amb més consum de CPU

Crea:

```text
topProcessos.ps1
```

El script ha de mostrar els **10 processos amb més consum de CPU**.

La sortida ha de mostrar únicament:

```text
Name
Id
CPU
```

Després mostra també:

```text
Nombre total de processos: ...
```

> Aquí primer comprovem el pipeline que ordena els processos i agafa els deu primers amb les tres propietats:

```powershell
PS C:\Users\Administrador> $processos = @(Get-Process)
PS C:\Users\Administrador> $processos | Sort-Object CPU -Descending | Select-Object -First 10 Name, Id, CPU
Name              Id     CPU
----              --     ---
VirtualBoxVM   22324 2881,80
xvpn           23100  397,05
opera          15468  291,19
explorer        8220  196,72
opera          12672  178,42
msedgewebview2 25884  122,47
msedgewebview2 21072   78,22
opera          23864   68,88
PS C:\Users\Administrador> $processos.Count
313
```

> Ara ho executem des del fitxer. Al script hem afegit Format-Table per mostrar la taula i després el nombre total:

```powershell
PS C:\Users\Administrador> & ".\scripts tasca\topProcessos.ps1"
Name              Id     CPU
----              --     ---
VirtualBoxVM   22324 2881,95
xvpn           23100  397,23
opera          15468  291,27
explorer        8220  196,72
opera          12672  178,45
msedgewebview2 25884  122,47
msedgewebview2 21072   78,22
opera          23864   68,88

Nombre total de processos: 313
```

> El sort va abans del First 10, perquè si ho féssim al revés només ordenaríem deu processos qualsevol. El total del final és el de tots els processos guardats, no el dels deu que hem seleccionat. La columna CPU és el temps acumulat en segons, no un percentatge.

### Script final

```powershell
# Ordenem abans d'agafar els deu primers processos.
$processos = @(Get-Process)
$topProcessos = $processos |
    Sort-Object CPU -Descending |
    Select-Object -First 10 Name, Id, CPU

$topProcessos | Format-Table -AutoSize
Write-Output "Nombre total de processos: $($processos.Count)"
```

## 4. Anàlisi de fitxers d'una carpeta

Crea:

```text
analitzaCarpeta.ps1
```

El script ha de treballar amb la carpeta des d'on s'executa.

Ha de mostrar:

- nombre total d'elements;

- els cinc fitxers més grans;

- nom i mida d'aquests fitxers.


Investiga les propietats retornades per:

```powershell
Get-ChildItem
```

i utilitza-les per construir el pipeline.

> Tingues en compte que pots trobar tant fitxers com carpetes.

> Per provar aquest punt hem preparat una carpeta amb 6 fitxers de mides diferents i 2 subcarpetes. Primer mirem les propietats que ens dona Get-ChildItem:

```powershell
PS C:\Users\Administrador> Get-ChildItem | Select-Object Name, Length, PSIsContainer
Name        Length PSIsContainer
----        ------ -------------
carpetaA                    True
carpetaB                    True
fitxer1.txt 10             False
fitxer2.txt 50             False
fitxer3.txt 100            False
fitxer4.txt 200            False
fitxer5.txt 500            False
fitxer6.txt 1000           False
```

> Ara traiem les carpetes i ordenem només els fitxers per Length:

```powershell
PS C:\Users\Administrador> Get-ChildItem | Where-Object { $_.PSIsContainer -eq $false } | Sort-Object Length -Descending | Select-Object -First 5 Name, Length
Name        Length
----        ------
fitxer6.txt   1000
fitxer5.txt    500
fitxer4.txt    200
fitxer3.txt    100
fitxer2.txt     50
```

> Guardem el recompte de tots els elements abans de filtrar, així també compta les carpetes. Executem el script dins de la carpeta de prova:
> El fitxer esta guardat fora de la carpeta de prova i per aixo el cridem amb la seva ruta.

```powershell
PS C:\Users\Administrador> & "C:\Users\MSI\Desktop\git\ASIX-ASO\powershell\08.Scripts\scripts tasca\analitzaCarpeta.ps1"
===== ANÀLISI DE LA CARPETA =====
Nombre total d'elements: 8

Cinc fitxers més grans (mida en bytes):

Name        Length
----        ------
fitxer6.txt   1000
fitxer5.txt    500
fitxer4.txt    200
fitxer3.txt    100
fitxer2.txt     50
```

> Ara ho provem en una carpeta buida:

```powershell
PS C:\Users\Administrador> & "C:\Users\MSI\Desktop\git\ASIX-ASO\powershell\08.Scripts\scripts tasca\analitzaCarpeta.ps1"
===== ANÀLISI DE LA CARPETA =====
Nombre total d'elements: 0

Cinc fitxers més grans (mida en bytes):
```

> Ens dona 8 elements en total, però al rànquing només surten fitxers. `PSIsContainer` ens serveix per distingir les carpetes i `Length` és la mida del fitxer en bytes. El fitxer que hi ha dins de carpetaA no surt perquè no hem fet cap cerca recursiva.
>
> El script fa servir el directori actual, no la carpeta on està guardat el `.ps1`. També l’hem provat en una carpeta buida i en una que només té carpetes: mostra el total sense inventar fitxers ni donar error.

### Script final

```powershell
# Get-ChildItem treballa amb el directori actual.
$elements = @(Get-ChildItem)
$fitxers = @($elements | Where-Object { $_.PSIsContainer -eq $false })
$fitxersGrans = $fitxers |
    Sort-Object Length -Descending |
    Select-Object -First 5 Name, Length

Write-Output "===== ANÀLISI DE LA CARPETA ====="
Write-Output "Nombre total d'elements: $($elements.Count)"
Write-Output ""
Write-Output "Cinc fitxers més grans (mida en bytes):"
$fitxersGrans | Format-Table -AutoSize
```

## 5. Diagnosi bàsica del sistema

Crea:

```text
diagnosi.ps1
```

Ha de mostrar almenys quatre apartats.

### Processos

Mostra els cinc processos amb més CPU.

Propietats:

```text
Name
Id
CPU
```

### Serveis

Mostra:

```text
Total de serveis
Serveis en execució
Serveis no executats
```

### Fitxers

Mostra els tres fitxers més grans de la carpeta actual.

Propietats:

```text
Name
Length
```

### Estat final

Al final mostra un petit resum:

```text
===== RESUM =====

Processos analitzats: ...
Serveis analitzats: ...
Fitxers analitzats: ...
```

Organitza el script perquè sigui fàcil de llegir.

Pots utilitzar comentaris per separar els diferents blocs:

```powershell
# =====================
# PROCESSOS
# =====================
```

> Per al de diagnosi hem anat ajuntant les parts que ja havíem provat: processos, serveis i fitxers. Tornem a comprovar la selecció dels tres fitxers més grans a la carpeta de prova:

```powershell
PS C:\Users\Administrador> Get-ChildItem | Where-Object { $_.PSIsContainer -eq $false } | Sort-Object Length -Descending | Select-Object -First 3 Name, Length
Name        Length
----        ------
fitxer6.txt   1000
fitxer5.txt    500
fitxer4.txt    200
```

> Al script ho separem amb comentaris i títols per veure cada apartat. Aquesta és la prova completa amb la mateixa carpeta de 6 fitxers i 2 subcarpetes:
> El fitxer esta guardat fora de la carpeta de prova i per aixo el cridem amb la seva ruta.

```powershell
PS C:\Users\Administrador> & "C:\Users\MSI\Desktop\git\ASIX-ASO\powershell\08.Scripts\scripts tasca\diagnosi.ps1"
===== PROCESSOS =====

Name            Id     CPU
----            --     ---
VirtualBoxVM 22324 3497,70
xvpn         23100  592,92
opera        12672  368,80
opera        15468  365,27

===== SERVEIS =====
Total de serveis: 297
Serveis en execució: 132
Serveis no executats: 165

===== FITXERS =====

Name        Length
----        ------
fitxer6.txt   1000
fitxer5.txt    500
fitxer4.txt    200

===== RESUM =====

Processos analitzats: 299
Serveis analitzats: 297
Fitxers analitzats: 6
```

> Ara ho provem en una carpeta buida:

```powershell
PS C:\Users\Administrador> & "C:\Users\MSI\Desktop\git\ASIX-ASO\powershell\08.Scripts\scripts tasca\diagnosi.ps1"
===== RESUM =====

Processos analitzats: 300
Serveis analitzats: 297
Fitxers analitzats: 0
```

> Aquí es veuen els quatre apartats. El resum compta tots els processos i serveis que hem guardat i els 6 fitxers analitzats, encara que a les taules només mostrem els 5 processos i els 3 fitxers més grans.
>
> Les carpetes no les hem sumat com a fitxers. Hem fet servir Format-Table a cada taula perquè la dels processos i la dels fitxers es mostrin amb les seves columnes. També ho hem provat sense fitxers per comprovar que el resum pot mostrar 0.

### Script final

```powershell
# =====================
# DADES DEL SISTEMA
# =====================
$processos = @(Get-Process)
$serveis = @(Get-Service)
$enExecucio = @($serveis | Where-Object { $_.Status -eq "Running" })
$noExecutats = @($serveis | Where-Object { $_.Status -ne "Running" })
$elements = @(Get-ChildItem)
$fitxers = @($elements | Where-Object { $_.PSIsContainer -eq $false })

# =====================
# PROCESSOS
# =====================
Write-Output "===== PROCESSOS ====="
$processos |
    Sort-Object CPU -Descending |
    Select-Object -First 5 Name, Id, CPU |
    Format-Table -AutoSize

# =====================
# SERVEIS
# =====================
Write-Output "===== SERVEIS ====="
Write-Output "Total de serveis: $($serveis.Count)"
Write-Output "Serveis en execució: $($enExecucio.Count)"
Write-Output "Serveis no executats: $($noExecutats.Count)"
Write-Output ""

# =====================
# FITXERS
# =====================
Write-Output "===== FITXERS ====="
$fitxers |
    Sort-Object Length -Descending |
    Select-Object -First 3 Name, Length |
    Format-Table -AutoSize

# =====================
# RESUM
# =====================
Write-Output "===== RESUM ====="
Write-Output ""
Write-Output "Processos analitzats: $($processos.Count)"
Write-Output "Serveis analitzats: $($serveis.Count)"
Write-Output "Fitxers analitzats: $($fitxers.Count)"
```

# Requisits generals

Tots els scripts han de:

1. tenir extensió `.ps1`;
    
2. executar-se amb PowerShell 7;
    
3. utilitzar noms de variables descriptius;
    
4. tenir el codi correctament indentat;
    
5. incloure algun comentari quan sigui necessari;
    
6. evitar codi que no sigui necessari;
    
7. mostrar una sortida comprensible per a l'usuari.
    

Abans de donar un script per acabat:

```
prova cada part a la consola
        ↓
comprova el resultat
        ↓
incorpora-la al script
        ↓
executa el script complet
```
